# Подготовка к защите

1. Откройте главную через `index.html` и покажите навигацию между четырьмя страницами.
2. Начните тест, попробуйте перейти дальше без ответа и покажите сообщение об ошибке. Выберите ответ, перейдите дальше и вернитесь назад. Первый выбор останется отмеченным.
3. Завершите тест. Покажите карточку результата и четыре шкалы — смелость, стратегию, командную работу и креативность.
4. Откройте каталог. Введите `wizard` и покажите найденные карточки и профиль одного персонажа.

В `data.js` каждому варианту соответствует массив из четырёх чисел. jQuery записывает выбранный вариант в `answers` и обновляет разметку. При завершении обычный JavaScript суммирует баллы, переводит их в диапазон 0–100 и сравнивает профиль пользователя с профилями персонажей. Bootstrap отвечает за сетку, мобильное меню, модальное окно каталога и FAQ.
