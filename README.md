# Arena ID — Who are you from Clash Royale?

Учебный проект по Web Technologies: personality test на HTML, CSS, Bootstrap, JavaScript и jQuery. Интерфейс на английском, пояснения к запуску и защите — на русском. Без React, сборщика, аккаунтов и базы данных.

## Как запустить

**Windows:** запустите `START.bat`, оставьте окно сервера открытым и перейдите по адресу **http://127.0.0.1:3000**.

Либо откройте терминал в папке проекта:

```sh
node server.js
```

Нужен Node.js 18 или новее. `npm install` не требуется. Скрипт `START.bat` также умеет находить Node.js, который установлен вместе с Codex на этом компьютере.

Другие варианты: расширение **Live Server** в VS Code (Open with Live Server для `index.html`) или `python -m http.server 3000 --bind 127.0.0.1` при установленном Python. Остановить сервер: `Ctrl+C`.

**Не открывайте HTML двойным щелчком:** браузер блокирует загрузку локального JSON через `file://`. Для проекта нужен обычный локальный HTTP-сервер. Все библиотеки и изображения уже скачаны: после запуска интернет для работы сайта не нужен.

Если порт занят, завершите предыдущий сервер или задайте другой порт в PowerShell: `$env:PORT = '3001'`, затем `node server.js`.

## Что работает

- Четыре отдельные страницы с общей навигацией: главная, тест, персонажи, о проекте.
- 12 вопросов, 4 варианта ответа на каждый и 8 возможных результатов.
- Проверка никнейма и запрет перехода без выбранного ответа.
- Возврат к предыдущему вопросу с сохранением выбора.
- Автоматическое сохранение текущего теста и последнего результата в `localStorage`.
- Профиль из четырёх шкал, описание персонажа, сильная сторона, совет и два ближайших альтернативных результата.
- Копирование результата с ручным вариантом, если Clipboard API недоступен.
- Поиск по имени и описанию, фильтр по типу личности, сброс и состояние пустой выдачи.
- Модальные окна Bootstrap, FAQ-аккордеон и мобильное меню.
- Адаптивная сетка, управление клавиатурой, подписи полей, alt, ARIA и учёт reduced motion.

Никнейм и ответы не отправляются на сервер. Хранится только текущий тест и последний завершённый результат в этом браузере. Это развлекательный тест, а не психологическая диагностика.

## Алгоритм

Порядок характеристик в массивах: **Courage, Strategy, Teamwork, Creativity**. Каждый ответ содержит четыре числа от 0 до 3.

1. Складываем баллы отдельно по каждой характеристике.
2. Переводим сумму в шкалу 0–100: `Math.round(total / (12 * 3) * 100)`.
3. Для каждого персонажа считаем сумму абсолютных разностей его профиля и профиля пользователя.
4. Сортируем по возрастанию: минимальная разность даёт результат.
5. При равенстве используем алфавитный порядок ID, поэтому одинаковые ответы всегда дают одинаковый результат.

Шкалы независимы, поэтому их сумма не обязана быть 100. Алгоритм не показывает выдуманную «точность в процентах». При возврате назад меняется элемент массива ответов; баллы считаются заново только при завершении.

Чтобы изменить вопросы, редактируйте `questions.json`, сохраняя структуру `category`, `text`, `options`, `scores`. Для нового персонажа добавьте объект в `characters.json` и PNG с именем его `id`. При изменении количества вопросов обновите также текст на страницах и тесты. Если меняете смысл данных, поменяйте суффикс `v1` у ключей хранилища, чтобы старые ответы не применялись к новым вопросам.

## Проверки

```sh
node --test tests/scoring.test.js
```

Шесть тестов проверяют структуру данных и наличие изображений, известный расчёт, недопустимые ответы, замену ответа, равные результаты и достижимость всех восьми персонажей.

В браузере вручную проверьте: пустой никнейм → ошибка; корректный никнейм → вопрос; Next без ответа → ошибка; Back → выбранный ответ сохранён; перезагрузка → Continue saved quiz; завершение → результат; Copy → уведомление; поиск `wizard` + Thinker → 2 результата; невозможный запрос → пустая выдача.
