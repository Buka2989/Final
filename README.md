# Arena ID

Тест «Кто ты из Clash Royale?» для курса Web Technologies. У сайта четыре страницы: главная, тест, каталог персонажей и страница о проекте.

Чтобы запустить сайт, откройте `index.html` в браузере. Bootstrap, jQuery и изображения лежат в папке `assets`, поэтому проект можно открыть без интернета и без установки Node.js.

- `assets/css/style.css` — оформление поверх сетки и компонентов Bootstrap.
- `assets/js/data.js` — 12 вопросов, веса ответов и 8 персонажей.
- `assets/js/app.js` — вывод вопросов, проверка ответа, поиск в каталоге и расчёт результата.

Каждый ответ даёт от 0 до 3 баллов по четырём шкалам. Код переводит суммы в шкалу 0–100 и выбирает персонажа с наименьшей суммой абсолютных различий. При равном расстоянии результат определяется по алфавитному порядку ID.

Во время теста можно вернуться к предыдущим вопросам. При обновлении страницы тест начинается заново.
